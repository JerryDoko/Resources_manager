MIT 开源的本地媒体资源库。把漫画、条漫、小说、视频和照片按文件夹整理，在同一个桌面窗口中查找、阅读与播放。导入和分组只维护资源库索引，不搬动原文件。

主程序不内置作品或第三方站点预设，不提供付费解锁或 DRM 绕过。可选站点扩展仅提供页面适配规则，不包含作品正文；独立安装不消除内容授权风险。请只导入你拥有或获准使用的内容。MIT 授权仅覆盖项目自有代码，不覆盖用户文件和第三方依赖。详见 [LICENSE](LICENSE) 与 [第三方分发说明](THIRD-PARTY-NOTICES.md)。

## 开始使用

目前提供 macOS Apple Silicon 安装包；已发布的版本可在 [GitHub Releases](https://github.com/JerryDoko/Resources_manager/releases) 下载。安装后添加文件夹，即可建立资源库。

从源码运行需要 Node.js 20 和 npm：

```bash
npm ci
npm run resources
```

`npm run resources` 会启动服务并打开 Electron 内置窗口。macOS 也可以双击 `scripts/Start Resources Manager.command`。若只需要系统浏览器，可运行 `npm run resources:web`。

## 导入与整理

- 按漫画、条漫、小说、视频、照片五种类型添加文件夹；导入时可选择递归扫描子文件夹或只扫描当前文件夹，默认递归。
- 每条导入路径可单独调整递归范围、重新扫描或从库中移除。再次扫描会复用已收录文件，不会因重复导入而生成重复项。
- 视频和照片按文件夹归为系列。打开照片文件夹时会检查新增图片并自动导入。
- 在文件夹内多选文件，可创建逻辑分组，或移动到同类型的已有分组；磁盘上的文件位置保持不变。


## 浏览资源库

- 资源库支持搜索、标签筛选、评分和排序；大量内容分批加载，返回资源库时保留原有滚动位置。
- 文件夹内可按名称、添加日期或修改日期排序，再次点击同一字段切换正序与倒序。每个文件夹可以单独锁定排序字段和方向；未锁定时默认按名称正序。
- 文件夹内容支持按名称、路径、日期的包含搜索，以及按评分筛选。打开筛选后的文件时，阅读或播放队列遵循当前筛选结果与排序。
- 支持多标签页、项目评分、标签、缩略图和内容详情。将项目从资源库移除只删除索引，不删除源文件。


## 阅读与播放

**漫画与条漫**：浏览图片文件夹或 ZIP/CBZ 内容；条漫可向下连续阅读文件夹中的图片，宽度滑块默认 50%，并记住调整后的宽度。图片可从阅读器中定位到访达中的原文件。


**小说**：支持 TXT、EPUB、PDF。EPUB 可显示章节中的图片，并在滚动到章节边界后继续切换章节。

听书是小说阅读器的附加模式，支持音色、音量、倍速、对白规则、续听、悬浮窗和跨章预加载。每个工作区独立保存书籍、缓存和进度。下载后的多章文本在详情页按章节显示。

TXT / EPUB 阅读时会记住当前原文段落；开启「跟随原文」后，听书会滚动到正在朗读的段落。从悬浮播放器展开后恢复当前段落，切换章节从新章开头开始。站点扩展的「导入并阅读」会打开此次导入的章节，而不是旧续读位置。

阅读器右上角的下载按钮可「导出小说语音」：勾选已保存的章节并选择中文音色，使用本地 Kokoro 生成。单章导出 WAV，多章导出含逐章 WAV 的 ZIP；可取消生成。生成和保存都有成功、失败提醒；桌面版保存时可选择位置，完成后显示完整路径，并可在访达或文件夹中定位文件。浏览器版的保存位置由浏览器管理。导出使用原速和原始音量，不修改阅读位置、书籍文件或播放设置，也不会下载尚未保存的章节。播放及预加载任务优先于导出任务；长篇建议分批导出（最多 500 章、单章 512 MB、合计 1 GB）。

公开安装包不再携带 Kokoro 模型、eSpeak 数据、sherpa-onnx 或 Python。首次启用本地听书：先安装 [Python 3.11 或更新版本](https://www.python.org/downloads/)，在「小说导入 → 听书声音包」主动下载独立引擎，再导入自行下载并解压的 Kokoro v1.1 声音包。旧版已经安装到用户目录的引擎和模型可以继续使用。CPU 线程和生成测试见[声音包与性能设置](docs/kokoro-package-performance.md)。

新安装的引擎依赖上述 Python 安装，请保留它。模型目录导入只复制必要的模型数据，不运行下载目录内的脚本，也不修改原目录。

网页导入默认关闭，安装独立 JSON / ZIP 站点扩展后启用，并按工作区隔离。v1.2.1 支持原创示例一键安装、扩展包下载、站点规则编辑器和离线帮助；未知来源可以如实标为“未核实来源授权”，确认后安装，不要求冒称已获许可。扩展只能访问声明的 HTTPS 来源，无脚本、Cookie 或登录绕过。站点规则独立发布，通用下载、保存、去重和续章后端仍在主程序，不是独立执行的抓取小程序。首段先播、后两段及下一章预加载保留。已有下载章节可以离线阅读，未保存章节需要有效扩展。v1.2.0 仅支持 JSON 且不识别“未核实”状态，需升级应用。详见[网页扩展协议](docs/web-novel-extensions.md)。

新版支持同时安装多个站点扩展，按章节链接自动匹配；「小说 → 导入 → 网页扩展 → 管理网站扩展」可勾选启用或停用，重启后保留设置。同 ID 更新不改变启用状态，也不覆盖其他网站。浏览器读取扩展可使用隔离的 Electron 网页加载，允许 Cloudflare 验证资源正常加载，但不自动解决验证码。

v1.2.2 的网页窗口按工作区记住登录状态；网站让登录过期时仍需自行登录，不共享或导出账号凭证。下一章读取有加载反馈，评论与正文分开显示，只有带评论规则的扩展显示评论按钮。支持从声明的详情页补取书名、标签和封面，不覆盖自定义名称或封面；ESJ 扩展仍需真实会员页面校验。小说详情页和阅读器提供「打开小说存储位置」。

**视频**：记录播放进度，下次打开从上次位置继续，也可手动重置；切换全屏保留播放位置。支持 1、1.25、1.5、2、3 倍速，默认长按右方向键临时 3 倍速，松开后恢复。按 `K` 打开小弹窗，用滑块实时调整音量和固定档位速度，并为每个视频分别保存设置；“恢复默认”还原 100% 音量与 1 倍速，不重置进度。所有播放设置只存入资源库，不修改原视频文件。截帧可保存到本地、替换当前视频封面或替换视频文件夹封面。播放列表可调整顺序，并选择顺序播放、列表循环、单曲循环或随机播放。


## 多工作区

不同工作区使用独立的资源库数据库、缩略图和设置。可创建、重命名、删除工作区，并指定默认启动工作区。点击标题栏左侧图标五次，或按 `⌘⇧.`（Windows/Linux 为 `Ctrl+Shift+.`）打开切换界面。


## AI 控制与更新

在设置中启用 AI 控制后，可为本机接口生成令牌并设置权限：

| 权限 | 可用动作 |
| --- | --- |
| 读取级 | 搜索资源库、查看系列和统计、读取标签 |
| 可恢复级 | 调整评分和排序、添加标签、识别图片并为所在系列打标签 |
| 危险级 | 重置进度、从资源库移除系列；执行前须在应用内确认 |

识图需要自行配置兼容 OpenAI Chat Completions 的视觉模型地址、模型和密钥。仓库中的 `plugins/resources-manager` 提供本地 MCP 接入；应用运行且 AI 控制启用后，插件会连接本机服务，仍受上述权限限制。

在本仓库根目录安装 Codex 插件：

```bash
codex plugin marketplace add "$(pwd)"
codex plugin add resources-manager@personal
```

安装后在新对话中启用 Resources Manager 插件。危险动作仍需回到应用窗口确认。

设置页可手动检查 GitHub 更新；发现新版本时也会显示更新提醒。更新检查不会自动安装新版本。

## 数据与隐私

- 资源库索引、评分、标签、进度和设置保存在本机 SQLite 中；设置页支持导出与恢复备份。
- 开发运行时数据默认位于 `data/profiles/<配置 ID>/`；打包应用的数据位于 macOS 应用支持目录。可用 `RESOURCES_MANAGER_DATA` 指定数据根目录。
- 常规导入和浏览不需要云服务。检查更新会访问 GitHub；使用 AI 识图时，选中的图片会发送到你配置的视觉模型服务。未启用 AI 时不会执行识图请求。
- 安装包采用 ad-hoc 签名，尚未经过 Apple 公证；macOS 可能提示安全确认。

## 开发与打包

```bash
npm run build        # 构建应用
npm run test:novel   # 小说与扩展测试（真实 Kokoro 测试另需本地运行时）
# 先构建，再用隔离书库测试 Mac 内置窗口：
node scripts/test-novel-location-desktop.mjs
npm run release:mac  # 生成 macOS arm64 DMG 和 ZIP
```
