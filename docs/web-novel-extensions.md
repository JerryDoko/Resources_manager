# 用户安装的网页扩展

公开版默认不启用网页小说抓取，也不附带第三方小说站点预设。网页能力以可卸载的
声明式 JSON 扩展提供；只有安装后才出现链接输入和导入按钮。
扩展保存在当前工作区，不自动传播到其他工作区。

来源状态与说明由扩展发布者填写，程序不判断或核验一部作品的版权状态。
未知状态可以如实标注，不应把参考章节链接当作已取得许可的证明。

## 安装和移除

在「小说 → 导入 → 网页扩展」可安装原创示例，或选择自行取得的 JSON / ZIP，核对访问范围与来源声明后确认。
新版支持同时安装多个扩展，可一次选择多个 JSON / ZIP 文件。「管理网站扩展」打开独立管理页面，列出网站、版本、读取方式及启用状态；勾选立即保存到当前工作区，重启后保持不变。
导入和自动续章根据链接的完整 HTTPS 来源匹配已启用扩展，不再依赖最后安装的扩展。同一网站若有多个已启用规则，会提示冲突，需要只保留一个勾选。
同 ID 重新安装仅更新该扩展并保留原有启用状态，不删除其他规则。旧单扩展文件会自动读取；第一次修改时写入多扩展配置。仅打开页面不会写入或重置状态。
新版的「创建站点扩展」支持填写 HTTPS 来源、正文、章节标题、书名、目录与下一章 CSS 选择器，以及可选的正文排除规则，校验后安装或导出 JSON。
来源状态、说明与 HTTPS 参考链接必填。未知来源可以选择 `unverified`（未核实），如实说明情况后仍可安装，不要求冒称原创或已取得许可。参考链接可以是章节或来源说明页，不会自动把第三方站点标为已授权。

- [下载原创示例 ZIP](https://github.com/JerryDoko/Resources_manager/releases/download/v1.2.0/Resources-Manager-Web-Extension-Demo-1.0.0.zip)
- [下载原创示例 JSON](https://github.com/JerryDoko/Resources_manager/releases/download/v1.2.0/Resources-Manager-Web-Extension-Demo-1.0.0.json)
- [示例内容与 MIT 授权](web-extension-demo/README.md)
- [安装与常见错误](novel-install-help.md)

v1.2.0 安装包仅支持 JSON：先解压 ZIP，再选根目录 `manifest.json`。v1.2.1 支持直接安装 ZIP。
示例只适配仓库原创短篇《灯塔来信》，不适配第三方小说网站。示例安装不联网执行程序，导入章节需要联网；听书另需引擎与模型。
ZIP 根目录仅允许 `manifest.json`、`README.md`、`GUIDE.md`、`LICENSE`，最多 4 个文件，总包不超过 256 KB，JSON 解压后不超过 32 KB，不允许子目录、脚本或符号链接。

取消勾选或点击对应扩展的移除图标，只停止该网站的新网页下载，其他网站不受影响；已保存的书籍、章节和进度不删除。
未安装时，包括旧书的自动续章在内，任何未保存章节都不会联网下载。
已保存章节、本地 TXT/EPUB 的跨章阅读和听书不受影响。

## 协议

这是给站点作者的格式示例，不是可直接用于第三方小说站的下载器。
`example.org` 是文档示例域名，页面必须由作者另行提供。

```json
{
  "format": "resources-manager.web-novel.v1",
  "id": "my-original-stories",
  "name": "我的原创故事",
  "version": "1.0.0",
  "license": "MIT",
  "authorization": {
    "basis": "own-content",
    "statement": "此站点由故事作者运营，站内原创内容获准保存至个人资源库并朗读。",
    "reference": "https://example.org/rights"
  },
  "origins": ["https://example.org"],
  "selectors": {
    "content": "article",
    "title": "h1",
    "bookTitle": "header .book-title",
    "bookLink": "a[rel=index]",
    "next": "a[rel=next]"
  }
}
```

`basis` 可为 `unverified`（未核实）、`own-content`（原创）、`permission`（获准）、`public-domain`（公版）。`unverified` 需要 v1.2.1 或更新版本，v1.2.0 的旧校验器不认识此值；不要用虚假的 `permission` 兼容旧包。
`license` 描述扩展本身的许可，不代表小说自动获准再发布。
所有选择器使用 CSS；书名元素也支持 meta 元素的 content 属性。
bookLink/next/exclude 可省略。exclude 用 CSS 指定正文容器内要移除的广告、标题或页面信息，不运行脚本。书籍目录链接是稳定去重键，建议站点作者提供。
新版还支持可选 `selectors.comments`，逐条提取指定的评论区域为纯文本，独立于 `selectors.content` 的小说正文。默认过滤脚本、导航、表单与侧栏，可通过 exclude 补充广告和评论操作区域。只保存网页当前已加载的评论，不自动翻评论分页或发送评论。评论随章节按工作区保存，阅读器点击评论图标可查看；评论不会进入朗读分段、语音导出、TXT 合集或阅读进度。重新导入同章节仅更新评论，不重复创建章节或重置正文进度。两种 JSON 备份均保留评论，旧备份仍可恢复。
扩展有评论规则时显示评论开关，即使当前章没有评论也可打开查看空状态；无评论规则的站点不显示。HTML 扩展可选择 `allowMissingTitles: true`，仅在有效正文已匹配时允许用页面标题或来源编号暂存，避免标题布局变化导致正文无法保存。默认仍严格校验标题；此选项不会允许登录页、验证页或无正文页面导入。导入成功后先保存分章 TXT 和 collection.txt，再打开应用阅读器；导入提示显示本地合集路径。
来源必须是 HTTPS 标准端口；每次重定向、目录链接和下一章都重新检查来源。
不支持脚本、Cookie、自定义请求头、认证、验证码或付费绕过，拒绝本机与内网地址。

## 适配和排错

1. 先确认内容允许相关保存与朗读，再检查一条公开章节页的 HTML。不要发布未经核实的许可声明。
2. 正文、章节标题、书名三个选择器必须命中。正文用最小的章节容器，避免整个 body 包含菜单和广告。书名可以取 meta 的 content 属性。
3. 目录、下一章选择器指向带 href 的链接；同一本书的目录链接必须保持一致，用于去重。
4. 在原站被拒绝、要求登录或出现验证码时停止，不靠扩展绕过限制。
5. www 与非 www 是不同来源，跨域重定向与下一章来源都需要显式列出。来源是整个域名范围，不是单条页面的授权证明。
6. 页面结构变更会使规则失效。更新扩展后再测试当前章、下一章、最后一章和重复导入；安装规则不会自动重复导入已经保存的书籍。

主程序不内置第三方站点预设和作品正文。站点规则放在独立扩展项目中，单独打包、安装、更新与移除；现有通用网页下载、导入、去重、跨章阅读与听书逻辑保留在主程序。当前扩展包是声明式数据，不是独立抓取进程或可执行小程序。
## 浏览器读取扩展

新版支持可选 `transport: "browser"`，用于直接 HTTP 请求返回验证页、但正常浏览器能打开的章节。
需要通过 Electron 桌面启动；只运行 Next.js 网页服务时会提示无法使用。
当前浏览器读取仅开放 ixdzs8.com、69shuba.com、esjzone.cc 和 n.novelia.cc 的声明域名；适配选择器仍来自单独安装的扩展，不内置小说正文。
安装确认会说明该网站的网页脚本会在隔离浏览器运行；允许 HTTPS 的 `challenges.cloudflare.com` 作为验证脚本、子框架等资源加载，但不允许将章节主页面或目录/下一章跳转到这个域名。本地文件权限、应用接口、弹窗、其他外部域名和下载仍被禁止。
遇到站点安全验证需用户自行处理，应用不会自动解决验证码、伪造授权或绕过收费。

点击「打开网页」可主动打开隔离网页窗口。导入时如果遇到登录、安全验证、正文缺失或加载异常，会自动显示网页而不是立即关闭。窗口提供「返回原章节」「刷新」「继续读取」「取消导入」；用户自行完成网站操作后返回原章节，匹配到正文会继续导入。等待操作最多四分钟，超时保留网页供查看，关闭后重试即可。标题或书名解析失败时也会重新打开网页，报告具体规则错误，不保存登录页或验证页。
工具栏和第三方网页是分离的渲染视图，网页没有应用预加载脚本或文件权限。新版将登录状态保存在本机、对应工作区的持久浏览器分区中，重启后可继续使用站点尚未过期的登录状态。不提取、导出密码或 Cookie，不跨工作区共享。第一次更新到此版本需重新登录一次；退出登录请在站点网页中操作，站点让登录过期时仍需重新登录。
ESJ 登录页所需的 core-js 2.4.1、SweetAlert2 6.10.1 脚本与样式按精确 CDN 地址和资源类型单独放行；不开放 CDN 其他文件、主页面跳转、广告或跟踪域名。

爱下电子书和 69 书吧扩展已根据正常浏览器返回的章节结构适配；69 书吧旧版 0.1.0 模板需要更新为 1.0.0（同 ID 更新，勾选状态保持）。站点仍可能再次要求安全验证，不能保证每次访问都成功。
多个站点扩展可同时启用，按链接自动匹配，勾选状态在重启后保留。旧版单扩展模式下已经被替换的规则需要重新导入一次，程序不能从不存在的旧文件恢复它们。
若 69 书吧仍报告浏览器不兼容或显示验证码，需用户在正常网页窗口自行处理；允许验证资源不保证站点接受 Electron 浏览器。可参考 [Cloudflare 排错文档](https://developers.cloudflare.com/cloudflare-challenges/troubleshooting/)。

## Novelia 和 ESJ Zone

Novelia 独立扩展通过网页使用的公开 JSON 接口读取已有中文译文，按返回的 `nextId` 接续下一章。优先 Sakura，其次有道；没有这两种译文时明确报错，不自动改读日文、不提交翻译任务。输入普通章节链接，不输入 API 地址或书籍目录。需要新版源码或支持 `transport: json` 的后续安装包；v1.2.1 旧包不支持。

ESJ Zone 0.4.0 独立包增加章节目录书名、标签、详情页封面规则，仍是待真实会员页面校验的模板，不宣称已完成真实会员章节或续章验收。有效正文标题暂时缺失仍可保存，登录、验证和无正文页面不会保存。新版会显示登录网页，用户可自行登录再返回原章节；若正常正文仍不匹配，请提供正常打开后的 HTML 继续校验，不提供密码或 Cookie。

## 书籍信息与本地位置

HTML 扩展可声明 `metadata.tags`（章节页标签）、`metadata.cover`（章节页封面）与 `metadata.coverOrigins`（额外的 HTTPS 图片来源，不能用于章节跳转）。可选 `metadata.details` 从同站详情页补取信息：`request` 为 `/detail/{1}.html` 这样的路径模板，`bookTitle`、`tags`、`cover` 为 CSS。HTML 模板的 `{0}`、`{1}` 从完整章节路径的非空段取值，如 `/forum/1784713189/595567.html` 的 `{1}` 为书籍编号；HTML 书名 CSS 同样支持这些占位符。此规则与 JSON 接口路径的取值方式不同。

浏览器扩展的详情补取使用同一工作区的登录会话，后台读取，不另弹无正文窗口；失败时保留已下载章节并说明原因。详情路径与重定向仍受来源限制，封面额外校验公开网络地址、重定向来源、6 MB 大小和实际图片格式；支持没有常规图片后缀的 `.file`。图片按工作区保存为本地 WebP，不修改正文、原始文件或阅读位置。标签合并到已有系列标签，重复导入不重复建标签；自定义书名和封面不会被覆盖。

若代理使用 Fake-IP 导致服务器无法下载 ESJ 封面，桌面版可通过 Electron 网络栈重试。此兼容路径仅允许扩展明确声明的 `https://images.novelpia.com/imagebox/cover/` 文件，逐次检查重定向，并限制为 6 MB；不发送登录凭证，不开放任意 CDN 或本地网络访问。

小说详情页及阅读器的文件夹图标可打开存储位置，定位到本地 TXT/EPUB 或网页下载的 `collection.txt`；分章 TXT 在同目录的 `chapters` 子目录。原文件丢失时显示错误，不创建空文件代替。

JSON 扩展用 `json` 而非 `selectors` 声明：`pathPrefix` 是章节路径前缀，`request` 是同源公开接口路径，`bookURL` 是稳定书籍路径，`nextURL` 是下一章路径。路径中的 `{0}`、`{1}` 等来自章节路径前缀之后的各段，`{next}` 只能用于下一章路径。`title`、`bookTitle`、`content` 是按优先级排列的顶层 JSON 字段名，正文须为字符串段落数组；`next` 是下一章编号字段名。扩展不能指定任意脚本、请求头或登录凭证，接口下载仍执行 HTTPS 来源、重定向与本机/内网限制检查。

Novelia 配置 `json.browser: true`，通过受限的内置浏览器正常加载同源 JSON，兼容当前代理 Fake-IP 网络。需要完整桌面启动，不导入外部浏览器 Cookie、不访问 auth.novelia.cc。浏览器接口读取只开放 `n.novelia.cc`，不会使任意 JSON 扩展获得浏览器访问权限；普通 HTTP 下载的内网保护不变。
