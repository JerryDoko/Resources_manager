# Windows 听书声音包与性能设置

## 下载后放哪里

在程序内打开「小说 → 小说导入 → 听书声音包」。界面中的「模型存放位置」显示当前电脑的实际路径，点击「打开存放目录」即可在资源管理器中打开。

Windows 安装版的默认位置为：

```text
%APPDATA%\resources-manager\kokoro\models
```

在资源管理器地址栏输入上述路径可打开。自定义用户数据目录时，以程序显示的路径为准。源码版位于 `data\kokoro-runtime\models`。

1. 下载一个官方模型压缩包。
2. 完整解压，保留 ONNX、voices.bin、tokens.txt、espeak-ng-data、词典和规则文件。
3. 将整个模型文件夹放入程序显示的存放目录。
4. 点击「刷新目录」，选择「使用此目录」，再点击「安装所选模型 / 重试」。

程序也支持从其他位置安装，不必先移动已有文件。例如：

```text
D:\resources-manager\kokoro-multi-lang-v1_1
```

如果解压后内部还有一层同名 `kokoro-multi-lang-v1_1` 文件夹，程序会自动识别。带引号的路径也可以使用。

## 两种官方模型

| 模型 | 下载大小 | 官方下载 |
| --- | --- | --- |
| Kokoro v1.1 轻量版，INT8 | 约 140 MB | [下载轻量版](https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/kokoro-int8-multi-lang-v1_1.tar.bz2) |
| Kokoro v1.1 完整版，FP32 | 约 348 MB | [下载完整版](https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/kokoro-multi-lang-v1_1.tar.bz2) |

两者包含中文、英文等音色；本程序提供中文听书选择。轻量版体积较小，具体生成速度取决于处理器和线程配置，不能只按模型大小判断。官方模型说明：[sherpa-onnx Kokoro](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_1.html)。

## 安装方式

- **在线自动下载与配置**：选择模型后安装；自动配置独立 Python 和依赖，下载文件经过 SHA256 校验。
- **安装本地模型 / 离线声音包**：选择解压后的模型目录，程序自动识别版本，优先复用安装包内置 Python。无需重新下载模型。
- **完整离线包**：需要 `python`、`model`、`manifest.json`，程序按清单验证后安装，支持无网络电脑。只有模型且电脑没有内置运行时的情况下，需要联网配置 Python 与依赖。

运行时装入用户数据目录，不需要修改系统 Python。下载或安装失败可以在同一界面重试。界面会显示**当前实际使用的模型**；下拉框选中新模型并不表示安装已完成。

## 提高语音生成速度

打开「设置 → 听书性能设置」，或「小说导入 → 听书性能设置」。

| 模式 | CPU 线程 |
| --- | --- |
| 低占用 | 1 |
| 均衡 | 最多 2 |
| 优先速度 | 最多 4 |
| 自定义 | 1 到当前处理器支持的上限，最高 32 |

选择模式后可先点击**测试生成速度**。测试使用固定中文文本和独立临时缓存，显示模型加载时间、生成耗时、音频时长和实时系数；不会修改小说阅读位置，也不会保存当前选择。决定采用后点击**保存性能设置**，设置保存在用户数据目录，对所有资料库生效，下一次生成新片段时应用。

建议分别测试 2 和 4 线程，以自己电脑的结果为准。实时系数为「生成耗时 ÷ 音频时长」，越低越快，小于 1 说明生成速度快于正常播放。多线程不保证更快，测试时尽量暂停其他占用 CPU 的任务。

应用会保持语音进程、提前生成后续片段，并缓存已生成的音频。首段含模型加载开销；重复阅读能复用缓存。切换模型后重新打开阅读器。朗读倍速只影响播放速度，不是生成性能设置。当前发行版使用 CPU，界面不提供尚未支持的 GPU 加速开关。

## Windows 窗口控制

窗口右上角依次为最小化、最大化/还原、关闭。最大化与真正的全屏是不同操作。原先左侧红、黄、绿圆点已从 Windows 版移除。

## 常见错误

- `model/LICENSE` 不存在：旧版本把单独的模型目录当作完整包。更新到支持本地模型安装的版本后，再选「安装本地模型 / 离线声音包」。
- 缺少 tokens.txt 或 voices.bin：重新完整解压模型，不能只复制 ONNX 文件。
- 多个 ONNX 或多个模型目录：请选择具体的一个模型目录。
- 声音包未安装：先完成安装并确认界面显示实际模型，再开始听书。

模型文件和下载缓存仅保存在本机；测速使用固定文本，实际书籍正文由本地语音进程处理。
