# v1.1.11 - 小说阅读与本地听书

## 新增功能

- 小说默认以阅读模式打开；通过“听书”按钮切换朗读，阅读与听书保持同一本书的章节和位置。
- 小说导入页直接选择本地 TXT / EPUB；网页导入独立入口，支持后续章节读取、分章 TXT 和合集保存。
- 本地 Kokoro 中文朗读内置离线 Python 与声音模型，支持音色、倍速、音量、对白朗读规则和续听。
- 首段生成后立即播放，提前准备后两段和下一章开头；支持悬浮置顶播放器和返回阅读器。
- 详情页按实际章节展示 TXT / EPUB 目录、章节数和进度；支持已有听页书库复制迁入与去重。
- 书籍、缓存和进度按工作区隔离；本地文件索引导入不修改原始文件。

## 修复

- 修复听书悬浮窗口的 React hydration 不匹配错误。
- 修复删除旧配置后再次启动被自动迁移恢复的问题。
- 修复阅读/听书切换、迟到语音任务、重复章节推进和工作区切换后的旧会话问题。

## 本次发布

- 仅发布 macOS Apple Silicon（arm64）DMG；Windows 安装包暂不发布。
- macOS 深度 ad-hoc 签名校验、磁盘镜像校验和打包应用自动验收通过。
- 配置测试 5 项、小说测试 40 项通过；实际验收覆盖 TXT / EPUB 导入、真实 Kokoro、悬浮设置、跨章和基础媒体回归。
- 没有上传用户书库、音频缓存或私钥。

## 已知限制

- macOS 包没有 Apple Developer ID 签名及公证；其他 Mac 下载后的 Gatekeeper 行为尚未验证。
- 系统 TTS、超大型 EPUB 压力测试和 Windows 实机界面/音频输出尚未验收。
- 网页仅支持无需登录的静态正文，不绕过验证码；网络环境可能影响下载和更新检测。
- 现有依赖仍存在 npm audit 安全告警（包括旧版 Next.js），本次未进行依赖安全升级，不代表安全审计通过。
