# Resources Manager v1.2.0 · MIT 开源分发版

仅提供 macOS Apple Silicon 安装包，本次不发布 Windows 包。

## 调整

- 项目自有代码采用 MIT；保留第三方许可，不把第三方运行时改标为 MIT。
- 从当前源码树移除含第三方作品的展示截图，移除第三方小说站测试链接。
- 网页读取改为默认关闭、按工作区安装的声明式 JSON 扩展；不提供小说站点预设。
- 扩展必须声明来源授权和 HTTPS 访问范围，重定向与续章都受限制；不执行扩展脚本。
- 不再分发 Kokoro、eSpeak 数据、sherpa-onnx、Python；首次听书需自行安装 Python 3.11+，
  然后主动下载独立引擎、导入解压后的 Kokoro 模型目录。
- 已安装在用户目录的旧听书运行时保留。书库、模型源目录、进度和原始媒体不修改。
- 增加完整版声音包导入、CPU 线程设置与独立生成速度测试；保留章节详情、悬浮听书、
  首段先播和跨章节预加载。
- 使用系统字体，不再打包 Google 字体；附带实际依赖清单和第三方许可证材料。

## 许可和源码

应用内 `Contents/Resources/licenses/` 包含项目 MIT、Electron/Chromium、Node、
JavaScript 依赖以及 libvips 的第三方通知。Release 同时提供
`Third-Party-Sources-v1.3.2.zip`，含 libvips 对应源代码下载包、构建脚本、补丁
与 LGPL 编码识别库 jschardet 的完整源码和重建说明。
允许替换 LGPL 动态库以及为调试修改而进行逆向工程。

本次不改写已有 Git 历史、不删除旧版 Release；历史素材仍需独立核查。
开源授权和扩展许可声明不等同于法律审查，也不保证所有内容在所有地区均可合法使用。

## 实际验证

- `npm run build` 通过；小说测试 54 项、工作区回归 5 项全部通过。
- 最终 macOS 安装包在隔离书库中通过桌面回归，无运行时错误：首次下载独立引擎、
  完整版声音包导入、103 个音色、首段播放、续听、跨章、EPUB 图片、悬浮窗、
  本地 TXT/EPUB 导入，以及 PDF、照片、漫画、视频回归。
- 固定中文文本在本机 2 线程测试：模型加载约 0.74 秒，生成约 7.13 秒，音频
  13.47 秒，实时系数 0.529。此结果不是其他设备的性能承诺。
- 包内容检查确认没有 Python、语音模型、用户数据库、字体或旧截图；
  收集 118 项生产依赖记录与许可，附带 Next 内嵌模块及原生组件许可。
- DMG 校验、两个 ZIP 的完整性检查、应用深度 ad-hoc 签名验证均通过。

## 安装

DMG 采用 ad-hoc 签名，未经过 Apple Developer ID 签名和公证。
Windows、非 Apple Silicon Mac 和另一台 Mac 上的 Gatekeeper 行为未做实机验证。
