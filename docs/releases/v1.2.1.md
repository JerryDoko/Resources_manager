# Resources Manager v1.2.1 · 独立网页扩展与安装指南

本次只发布 macOS Apple Silicon（arm64）DMG 和 ZIP，不发布 Windows。

## 更新

- 保留网页导入、章节保存、去重、自动续章、阅读和听书；第三方站点规则通过独立 JSON / ZIP 包安装，不内置在应用中。
- 新增 ZIP 扩展安装，支持原创示例一键安装、扩展下载和站点规则编辑器。
- 来源状态增加“未核实来源授权”，允许如实填写来源后确认安装，不要求冒称原创或已获许可；应用显示该状态，不将来源声明视为核验结果。
- 扩展按工作区隔离，可安装、替换和移除；移除不删除已保存的章节或阅读进度。
- 安装只解析声明式 JSON，不执行脚本；拒绝子目录、符号链接与超限 ZIP，HTTPS 来源限制和内网访问限制保持不变。
- 增加离线安装与排错指南，以及扩展、Python、Kokoro 模型、旧 Books 迁入和 CPU 性能设置的帮助链接。
- 简化无效扩展的错误提示，切换适配规则后清空旧站点链接。
- 修复短篇中文网页被误判为日文编码：优先采用 BOM、HTTP / HTML 编码声明，合法 UTF-8 不再被猜测结果覆盖。
- 打包使用独立生产构建目录，避免开发服务覆盖发布文件造成首页 500 或缺少模块。

站点适配包是独立的数据扩展项目，通用抓取后端仍在主程序中，不是独立运行的抓取可执行程序。

## 安装扩展

「小说 → 导入 → 网页扩展 → 从文件安装」，选择独立扩展 ZIP / JSON，核对访问范围和来源说明后确认，再输入章节链接导入。
应用自带原创示例，不包含真实小说正文或第三方站点适配规则。

v1.2.0 不支持新增的“未核实”状态，使用此类扩展前须升级到 v1.2.1。

[下载独立扩展 ZIP](https://github.com/JerryDoko/Resources_manager/releases/download/v1.2.1/wcshuba-1.0.0.zip) · [下载 JSON](https://github.com/JerryDoko/Resources_manager/releases/download/v1.2.1/wcshuba-1.0.0.json) · [独立扩展项目源码](https://github.com/JerryDoko/Resources_manager/releases/download/v1.2.1/Novel-Web-Extensions-Source-1.0.0.zip)。这些是可选附件，主程序安装包不包含该站点规则。

## 保留的数据与许可

升级不修改原始媒体、模型源目录或已有书库。Kokoro 引擎、Python 和模型仍由用户独立安装；已有用户目录中的运行时保留。
自有代码采用 MIT，第三方许可与对应源码材料另附，不代表第三方作品的内容授权。

## 验证范围

已通过隔离生产构建与原生 SQLite 自检；小说测试 59 项通过、1 项可选模型测试跳过，工作区测试 5/5，独立扩展测试 2/2。
macOS 安装包实测通过 ZIP 安装/卸载、未核实来源提示、无效包保护、离线帮助、TXT/EPUB 导入、真实 Kokoro 完整版朗读、倍速音量、跨章续播与进度、悬浮窗及退出清理；图片、漫画、PDF、视频回归通过，前端错误列表为空。
已核验 DMG 与 ZIP 完整性、应用 ad-hoc 签名、发布附件 SHA-256；安装包没有用户数据库、语音模型或 Python 引擎。
独立第三方站点适配规则使用合成 HTML 结构测试；未进行该站点真实小说全文下载验收。
Windows、Intel Mac、其他 Mac 上的 Gatekeeper 行为未做实机验证。
应用采用 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证。
